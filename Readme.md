# Personal Portfolio Website

🔗 **Live Site:** https://personal-resume-site.muhammad-ahmee-mh.workers.dev/
 
This was one of my first projects at university, built as part of the "Introduction to Computer" course. The course focused on the fundamentals of web development — HTML for structure, CSS for styling, and JavaScript for interactivity.
 
As a final project, I designed and built a personal portfolio website to showcase my skills, background, and work. It was a hands-on way to apply everything I'd learned throughout the course, from writing semantic HTML to styling responsive layouts and adding basic interactivity with JavaScript.
 
Working on this project taught me a lot — not just about the technical side of web development, but also about planning a project from scratch, structuring content clearly, and paying attention to design details that make a website feel polished and user-friendly.
